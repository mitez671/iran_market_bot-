# داشبورد بازارهای مالی ایران

داشبوردی برای دنبال کردن بورس تهران، فرابورس، صندوق‌ها، اوراق، اختیار معامله، طلا و سکه، ارز، بورس کالا، بازارهای جهانی و اخبار — و چند شاخص تحلیلی برای اینکه «پول کجا برود».
روی گوشی اندروید (Termux) یا هر کامپیوتری که Node.js دارد اجرا می‌شود؛ بدون سرویس ابری، بدون پروکسی، و فقط با اینترنت خود دستگاه.

> این ابزار کمکی است، نه مشاور سرمایه‌گذاری. سیگنال‌ها قواعد ساده‌ی فنی و بنیادی‌اند و قبل از استفاده‌ی واقعی باید بک‌تست شوند.

## امکانات
- **دیده‌بان کامل بازار** (TSETMC): شاخص‌ها، همه‌ی نمادها، ورود پول حقیقی، صف‌ها، فرصت‌های غربالگری، سیگنال نمادهای دیده‌بان شخصی.
- **اوراق**: بازده تا سررسید اخزا و گام و صکوک، و مقایسه با میانه‌ی بازار.
- **طلا، سکه، ارز** (tgju): حباب سکه و **دلار ضمنی** (دلاری که قیمت طلای داخلی با انس جهانی فرض می‌کند).
- **صرف ریسک سهام**: بازده سود بازار (E/P) در برابر اخزا، به تفکیک گروه صنعت، و رشد سود لازم برای برابری با اوراق.
- **کاورد کال**: بازده سالانه‌ی خرید سهم + فروش اختیار خرید، حاشیه‌ی امنیت و مقایسه با اخزا.
- **حباب صندوق‌ها**: قیمت تابلو در برابر NAV ابطال (طلا، اهرمی، درآمد ثابت، سهامی).
- **تسهیلات بانکی با سپرده**: نرخ مؤثر واقعی هر وام با احتساب هزینه‌ی فرصت سپرده؛ طرح‌ها خودکار از rade.ir یا صفحه‌ی بانک‌ها (با الگو یا Claude) استخراج می‌شوند.
- **نرخ بهره‌ی واقعی**: با تورم مرکز آمار (دستی) یا تورم مورد انتظار.
- **پول کجا برود**: بازده سالانه‌ی پیش‌رو (اخزا، سپرده، کاورد کال، سهام) و بازده گذشته‌ی دلار، طلا، سکه، شاخص‌ها، انس و بیت‌کوین کنار هم.
- **اخبار** ایران و منطقه با تحلیل اثر بر بازارها، اطلاعیه‌های کدال، بورس کالا، خودرو و آهن.
- **Claude**: پرامپت آماده برای تحلیل (یا فراخوانی مستقیم با کلید API)، اعلان تلگرام/بله.

## اجرا
نیاز: [Node.js](https://nodejs.org) نسخه‌ی ۱۸ به بالا. هیچ پکیج دیگری لازم نیست.

**گوشی اندروید (Termux):**
```
pkg install nodejs
sh web/start-termux.sh
```
**کامپیوتر:**
```
cd web/server
node server.mjs
```
بعد در مرورگر باز کن: **http://127.0.0.1:8787** (اگر پورت پر بود، آدرس دقیق در پنجره‌ی سرور نوشته می‌شود).

### استفاده
1. **دانلود بدون VPN** را بزن (سایت‌های ایرانی)، بعد VPN را روشن کن و **دانلود با VPN** را بزن (سایت‌های خارجی). اینکه هر سایت با کدام دکمه گرفته شود در تب «🔀 سایت‌ها و VPN» قابل تغییر است و ذخیره می‌شود.
2. **اجرای کامل از داده‌های جمع‌شده** را بزن؛ این مرحله فقط تحلیل می‌کند و درخواست شبکه‌ای نمی‌فرستد.
3. **🧪 دمو** بدون اینترنت با داده‌ی ساختگی کار می‌کند.

راهنمای کامل‌تر: [`web/README.md`](web/README.md)

## ساختار
```
web/                    نسخه‌ی وب (همین که استفاده می‌شود)
├─ index.html, css/     صفحه
├─ js/                  منطق (بدون build): دریافت داده، تحلیل، شاخص‌ها، رابط کاربری
├─ server/              سرور محلی Node بدون وابستگی (127.0.0.1)
└─ start-termux.sh
iran_market_bot/        نسخه‌ی اولیه‌ی پایتونی
```

### برای توسعه
- مرورگر به‌خاطر CORS نمی‌تواند مستقیم از سایت‌های ایرانی بخواند؛ سرور همان فایل‌های `js/util|net|store|tsetmc|sources|collect.js` را در یک `vm` اجرا می‌کند
  و با تغییر این فایل‌ها خودش دوباره بارگذاری‌شان می‌کند. تغییر در `server/*.mjs` نیاز به اجرای دوباره‌ی سرور دارد.
- هر منبع داده یک شناسه در `js/collect.js` دارد؛ پیش‌فرض: سایت‌های ایرانی «بدون VPN»، خارجی «با VPN».
- تحلیل (`js/cycle.js`، `js/finance.js`، `js/engine.js`) بدون شبکه و بدون DOM است و فقط از داده‌های جمع‌شده می‌خواند.
- تنظیمات در `localStorage` و فایل `~/.iran_market_dashboard/settings.json` همان دستگاه ذخیره می‌شود؛ کلید API و توکن‌ها هرگز به سرور یا فایل نمی‌روند.
- سرور فقط به `127.0.0.1` گوش می‌دهد، درخواست با Host/Origin بیگانه را رد می‌کند و دریافت از آدرس‌های شبکه‌ی داخلی را مسدود می‌کند.
- منابع ویژه: `Fund/GetETFByInsCode` (NAV صندوق‌ها)، `Index/GetIndexB2History` (سابقه‌ی شاخص)، `api.tgju.org/.../summary-table-data` (سابقه‌ی قیمت)،
  rade.ir (`admin-ajax.php`، `action=rade_sync_filter`، فیلتر `deposit_block`). این سایت‌ها API رسمی ندارند؛ اگر ساختارشان عوض شد، فقط `js/tsetmc.js` یا `js/sources.js` را به‌روز کن.

# سامانه پایش و سیگنال‌دهی بازارهای ایران

## چه کار می‌کند
در هر چرخه این داده‌ها را جمع می‌کند و تحلیل می‌کند:

- **بورس و فرابورس و صندوق‌ها** (TSETMC): قیمت روزانه، حجم، و رفتار حقیقی/حقوقی. سیگنال از ترکیب RSI، MACD، میانگین‌ها، بولینگر، حجم مشکوک، **قدرت خریدار حقیقی** و **ورود/خروج پول حقیقی** ساخته می‌شود و حد ضرر و هدف بر اساس ATR پیشنهاد می‌شود.
- **اوراق بدون کوپن (اخزا، گام و مشابه)**: محاسبه YTM و مقایسه با نرخ بنچمارکی که خودت تعیین می‌کنی.
- **اختیار معامله**: ارزش منصفانه بلک-شولز با نوسان تاریخی دارایی پایه، نقطه سربه‌سر، اهرم و هشدار زیر ارزش ذاتی.
- **سکه و طلا و ارز** (tgju): محاسبه ارزش ذاتی از انس و دلار و **حباب** سکه امامی، نیم، ربع و طلای ۱۸.
- **بازارهای جهانی** (yfinance): انس طلا، نقره، مس، آلومینیوم، برنت، WTI، گاز، شاخص دلار، S&P500، بیت‌کوین، اتریوم؛ و اثر آن‌ها روی نمادهای ایرانی از طریق جدول `sensitivity`.
- **اخبار** فارسی و انگلیسی (Google News RSS + هر RSS دلخواه) با برچسب موضوعی و امتیاز احساسی.
- **تحلیل با Claude** روی کل داده‌ها، **اعلان** در تلگرام یا بله، و **گزارش HTML** در `reports/latest.html`.

## اجرای روزانه
- بار اول: `run_windows.bat` (نصب کتابخانه‌ها + تست منابع + اجرا)
- بعد از آن: فقط `start.bat` — همه داده‌ها را جمع می‌کند و **داشبورد** (`reports/latest.html`) را باز می‌کند.
- VPN را خاموش کن؛ TSETMC و سایت‌های ایرانی پشت VPN کار نمی‌کنند.

## تب‌های داشبورد
خلاصه (شاخص، ارزش معاملات، پول حقیقی، دلار، سکه، اثر اخبار، سیگنال‌ها) · فرصت‌های کل بازار (صف‌ها، ورود پول، حجم مشکوک)
· شاخص‌ها · دیده‌بان کامل همه نمادها · اوراق (اخزا، گام، صکوک) · صندوق‌ها · اختیار و آتی · طلا/سکه/ارز · بورس کالا
· خودرو/آهن/مسکن · بازار جهانی · اخبار با تحلیل اثر + کدال · وضعیت منابع

## تحلیل اخبار
۱) قواعد اقتصادی: اثر هر خبر روی بورس، دلار، طلا، نفت، مسکن و خودرو. ۲) شبکه عصبی خودآموز (MLP) که هر خبر را با واکنش واقعی
بازار در روز بعد برچسب می‌زند و هرچه بیشتر اجرا شود دقیق‌تر می‌شود (اعتمادش را در داشبورد گزارش می‌کند).
۳) اختیاری: مدل فارسی ParsBERT (`nlp.use_parsbert` در config).

## نصب و اجرا
```bash
pip install -r requirements.txt
python main.py --demo    # تست بدون اینترنت با داده ساختگی
python main.py --once    # یک بار اجرای واقعی
python main.py --loop    # اجرای دائمی (هر ۱۵ دقیقه در ساعات بازار)
```
همه تنظیمات در `config.yaml` است: دیده‌بان، نرخ بنچمارک اوراق، آستانه‌ها، حساسیت نمادها، اخبار و اعلان.

## اتصال به Claude (سه حالت در `llm.mode`)
1. **`manual` (پیش‌فرض، با همان اکانت Pro)**: هر چرخه یک فایل `reports/claude_prompt_*.md` می‌سازد. آن را در اپ Claude آپلود یا پیست کن تا تحلیل نهایی را بگیری.
2. **`claude_code`**: اگر Claude Code را نصب و با اکانت Claude وارد شده باشی، سامانه با `claude -p` خودکار تحلیل می‌گیرد. شرایط مصرف استفاده خودکار ممکن است با چت معمولی فرق کند؛ قبل از استفاده مستمر صفحه پلن و مستندات Claude Code را چک کن.
3. **`api`**: با کلید API از console.anthropic.com (اشتراک Pro شامل آن نیست و جداگانه حساب می‌شود). متغیر `ANTHROPIC_API_KEY` را تنظیم کن. این حالت می‌تواند برای اخبار لحظه‌ای جستجوی وب هم انجام دهد.

## اعلان
- **تلگرام**: ربات بساز (BotFather)، توکن و chat_id را در config بگذار.
- **بله**: مشابه تلگرام، از طریق ربات بله.
- با `only_on_change: true` فقط وقتی سیگنال یک نماد عوض شود پیام می‌آید.

## نکته‌های مهم
- **TSETMC و tgju API رسمی ندارند**؛ آدرس‌ها و نام فیلدها ممکن است تغییر کنند. هر منبع در فایل خودش (`sources/`) است تا به‌روزرسانی ساده باشد. اگر خطا دیدی، اولین جا را آن‌جا ببین.
- سایت‌های ایرانی گاهی IP خارج را محدود می‌کنند و برعکس، سرویس‌های خارجی (yfinance، Claude) ممکن است از داخل در دسترس نباشند. سامانه طوری نوشته شده که اگر یک منبع قطع شد، بقیه کار کنند.
- برای اوراق، **سررسید را دقیق** از مشخصات نماد در TSETMC وارد کن. نمادهای نمونه در config واقعی نیستند.
- **قیمت‌ها به ریال** هستند (TSETMC و tgju).
- بورس کالا (گواهی سپرده سکه/زعفران و آتی) اگر در TSETMC نماد داشته باشد، می‌توانی آن را در `stocks` یا `funds` اضافه کنی.

## گسترش‌های پیشنهادی
- NAV صندوق‌های طلا برای حباب صندوق (از سایت مدیر صندوق)
- زنجیره کامل اختیار معامله از دیده‌بان TSETMC و محاسبه نوسان ضمنی
- بک‌تست قوانین سیگنال روی داده تاریخی قبل از اعتماد به آن‌ها

> این سامانه ابزار کمکی است، نه مشاور سرمایه‌گذاری. سیگنال‌ها قوانین ساده فنی و بنیادی‌اند و قبل از استفاده واقعی باید بک‌تست شوند.

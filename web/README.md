# داشبورد بازارهای مالی ایران — نسخه‌ی وب (فقط HTML + CSS + JavaScript)

همان سامانه‌ی پایتونی، ولی کاملاً داخل مرورگر. پایتون، pip، SQLite و `.bat` لازم نیست.
نسخه‌ی پایتون در پوشه‌ی کناری (`../iran_market_bot`) دست‌نخورده مانده است.

## اجرا (روی گوشی، با Termux)
مرورگر نمی‌تواند مستقیم از سایت‌های ایرانی (TSETMC، tgju، کدال، اخبار) بخواند (CORS). برای همین دریافت داده در یک **سرور محلی کوچک در Termux** انجام می‌شود
و صفحه فقط از همان سرور می‌خواند. همه‌چیز روی خود گوشی می‌ماند؛ سرور فقط به `127.0.0.1` گوش می‌دهد.

**اولین بار (یک‌بار):**
```
pkg install nodejs
termux-setup-storage
```
**هر بار:**
1. در Termux بزن و پنجره را باز نگه دار:
```
sh /sdcard/Download/programming/iran_market_bot/web/start-termux.sh
```
2. در مرورگر گوشی باز کن: **http://127.0.0.1:8787/** (یا فایل `dashboard.html` را باز کن؛ خودش سرور را پیدا می‌کند و می‌برد). اگر پورت ۸۷۸۷ پر بود، سرور خودش پورت بعدی را می‌گیرد و آدرس دقیق را در Termux می‌نویسد؛ اگر همان داشبورد از قبل باز بود فقط آدرسش را می‌گوید.
   بالای صفحه باید «🟢 سرور ترموکس وصل است» ببینی.
3. پیش‌فرض: سایت‌های ایرانی **بدون VPN** و سایت‌های خارجی (اخبار غیرایرانی، Yahoo/stooq) **با VPN**. اگر خواستی در **⚙ تنظیمات** (تب «سایت‌ها و VPN») عوضشان کن (بدون VPN / با VPN / غیرفعال).
   انتخابت همان لحظه ذخیره می‌شود: هم در مرورگر و هم در فایل `~/.iran_market_dashboard/settings.json` روی خود گوشی؛ با بستن صفحه، عوض شدن پورت یا پاک شدن داده‌های مرورگر از دست نمی‌رود. کلید API و توکن‌ها در آن فایل نوشته نمی‌شوند.
   «برگرداندن به پیش‌فرض» انتخاب ردیف‌های نمایش‌داده‌شده را به حالت پیش‌فرض برمی‌گرداند.
4. VPN گوشی را **خاموش** کن و «🌐 دانلود بدون VPN» را بزن؛ بعد VPN را **روشن** کن و «🔒 دانلود با VPN» را بزن. روی هر دکمه تعداد سایت‌هایش نوشته شده است.
5. «✅ اجرای کامل از داده‌های جمع‌شده» را بزن؛ این مرحله فقط داده‌های جمع‌شده را تحلیل می‌کند و درخواست شبکه‌ای نمی‌فرستد.

دریافت داده با شبکه/VPN خود دستگاه در همان لحظه‌ی زدن دکمه انجام می‌شود (ترموکس هم از VPN گوشی عبور می‌کند). منطق دسته‌بندی با/بدون VPN همان است که در صفحه تنظیم کردی.
اگر دریافت یک سایت شکست بخورد، داده‌ی قبلیِ همان سایت می‌ماند و در «وضعیت منابع» با ❌ مشخص می‌شود. «🧪 دمو» بدون سرور و بدون اینترنت کار می‌کند.

**امنیت سرور:** فقط `127.0.0.1`؛ درخواست با Host یا Origin بیگانه رد می‌شود؛ دریافت از آدرس‌های داخلی/خصوصی (شبکه‌ی خانه، خود دستگاه) مسدود است؛
کلید API و توکن‌ها هرگز به سرور فرستاده نمی‌شوند؛ هر بار فقط یک دریافت همزمان.

## شاخص‌های اضافه (فقط در نسخه‌ی وب)
- **دلار ضمنی** (تب «طلا، سکه، ارز» و کارت خلاصه): قیمت داخلی ÷ (انس جهانی ÷ ۳۱٫۱ × گرم طلای خالص) برای طلای ۱۸، مثقال، ۲۴ عیار و سکه‌ها، و تتر؛ در مقایسه با دلار آزاد.
  میانگین طلای ۱۸ و مثقال معیار اصلی است (سکه حباب خودش را دارد). داده از همان tgju می‌آید.
- **تسهیلات بانکی** (تب «🏦 تسهیلات بانکی»): طرح‌های وام با سپرده را وارد می‌کنی (سپرده، ماه‌های انتظار، درصد مسدودی، سود سپرده، وام، نرخ، اقساط، کارمزد)؛
  نرخ مؤثر با احتساب هزینه‌ی فرصت سپرده حساب می‌شود.
  **دریافت خودکار:** آدرس صفحه‌ی طرح‌های هر بانک را در همان تب اضافه کن؛ با دکمه‌ی دانلود گرفته می‌شود (منبع «تسهیلات — نام بانک»، پیش‌فرض بدون VPN).
  طرح‌ها با الگوی ساده (تقریبی) یا با Claude (کلید API، یا پرامپت دستی در اپ Claude و پیست جواب) استخراج و به‌صورت پیشنهاد نشان داده می‌شوند.
  برای صفحه‌های عکسی/PDF/جاوااسکریپتی، متن را دستی پیست کن.
  **rade.ir** (منبع «rade.ir — وام‌های با مسدودی سپرده»، پیش‌فرض روشن و فقط وام‌های فعال): فهرست از فیلتر «مسدودی سپرده» سایت رده (`admin-ajax.php`, `rade_sync_filter`)
  و جزئیات هر وام از برچسب‌های صفحه‌اش (سقف وام، نرخ، مدت، نسبت وام به سپرده، خواب و مسدودی سپرده، سود سپرده). سپرده از «نسبت وام به سپرده» و سقف وام حساب می‌شود.
  عددهایی که در منبع نیست «ناقص» نشان داده می‌شوند و خودکار اضافه نمی‌شوند. بازده جایگزین پیش‌فرض = میانه بازده اخزا (auto) یا عدد دلخواه. طرح‌ها مثل بقیه‌ی تنظیمات ذخیره می‌شوند (`js/finance.js`).

- **صرف ریسک سهام** (تب «صرف ریسک سهام» و کارت‌های خلاصه): بازده سود بازار E/P (جمع سود ÷ جمع ارزش بازار سهام، از EPS و تعداد سهام دیده‌بان TSETMC) منهای میانه بازده اخزا؛
  به‌علاوه «رشد سود لازم» برای برابری با اخزا، جدول گروه‌های صنعت، و نمادهای سودده‌ای که E/P شان از اخزا بیشتر است. صرف ریسک هر روز ذخیره می‌شود و بعد از ۱۰ روز با گذشته مقایسه می‌شود.

- **کاورد کال** (تب «اختیار و آتی»): برای هر اختیار خرید، خرید سهم پایه (با بهترین قیمت فروش) + فروش اختیار (با بهترین قیمت خرید)؛
  بازده سالانه با قیمت ثابت و در صورت اعمال، حاشیه‌ی امنیت، سربه‌سر و اختلاف با اخزا. کارمزدها تقریبی و در تنظیمات `covered_call` قابل تغییرند.

- **حباب صندوق‌ها** (تب «صندوق‌ها» و کارت خلاصه): قیمت پایانی ÷ NAV ابطال − ۱ برای صندوق‌های طلا، اهرمی، درآمد ثابت و سهامی.
  NAV از منبع جدید «TSETMC — NAV صندوق‌ها (حباب)» گرفته می‌شود (`/Fund/GetETFByInsCode`، یک درخواست برای هر صندوق، بعد از دیده‌بان کل بازار؛ پیش‌فرض بدون VPN).
  اگر TSETMC ساختار پاسخ را عوض کند، پیام خطا اسم فیلدهای پاسخ را نشان می‌دهد.

- **نرخ بهره‌ی واقعی** (تب «📉 نرخ بهره‌ی واقعی»، تب «اوراق» و کارت خلاصه): تورم ماهانه‌ی مرکز آمار را دستی وارد می‌کنی (نقطه‌به‌نقطه، میانگین ۱۲ ماهه، ماهانه)
  و/یا تورم مورد انتظار خودت را؛ نرخ واقعی (فیشر) برای بازده اخزا، سود سپرده‌ی بانکی و هزینه‌ی هر طرح وام حساب می‌شود. تورم مبنا برای خلاصه و Claude قابل انتخاب است.

- **پول کجا برود** (تب دوم): بازده سالانه‌ی پیش‌رو (اخزا، سپرده، کاورد کال، E/P سهام با و بدون رشد هم‌اندازه‌ی تورم) با نسخه‌ی واقعی‌اش،
  هزینه‌ی وام‌های ثبت‌شده، و بازده ۳۰ روز / ۹۰ روز / ۱۲ ماه دلار، یورو، تتر، طلا، مثقال، سکه، شاخص‌ها، انس و بیت‌کوین.
  سابقه از دو منبع گرفته می‌شود: «TSETMC — سابقه‌ی شاخص کل، هم‌وزن و فرابورس» (`/Index/GetIndexB2History`) و «tgju — سابقه‌ی …» (`api.tgju.org/.../summary-table-data`)؛
  در سابقه‌ی محلی (حداکثر ۶۰۰ روز) ادغام می‌شوند. اگر ساختار پاسخ عوض شود، پیام خطا نمونه‌ی پاسخ را نشان می‌دهد.

## چه چیزی از پایتون به وب رفته؟
| پایتون | وب |
|---|---|
| `sources/*.py` | `js/tsetmc.js`، `js/sources.js` |
| `analysis/engine.py` | `js/engine.js` (خروجی عددی با نسخه‌ی پایتون یکسان تست شد) |
| `analysis/nlp.py` (MLP با scikit-learn) | `js/nlp.js` — قواعد اقتصادی همان‌هاست؛ مدل خودآموز **رگرسیون لجستیک روی n-gram حروف** است (نه MLP) |
| SQLite (`prices.db`، `news.db`، `signals.db`) | `localStorage` (`js/store.js`) |
| `analysis/dashboard.py`، `output.py` | `js/dashboard.js`، `js/output.js` |
| `main.py`، `config.yaml` | `js/cycle.js`، `js/config.js`، `js/app.js` |
| `--demo` | دکمه‌ی «🧪 دمو» (`js/demo.js`) |
| `--loop` | دکمه‌ی «🔁 خودکار» (صفحه باید باز بماند) |

## تفاوت‌ها و محدودیت‌ها
- **ParsBERT** و حالت `claude_code` (اجرای `claude -p`) در وب وجود ندارند.
- **Claude**: حالت `manual` پرامپت را آماده می‌کند (کپی/دانلود از نوار بالا). حالت `api` مستقیم از مرورگر به Anthropic
  می‌زند و کلید API در `localStorage` همین دستگاه می‌ماند؛ فقط روی دستگاه شخصی استفاده کن و هرگز آدرس صفحه را با کلید ذخیره‌شده به اشتراک نگذار.
- **اعلان** تلگرام/بله مستقیم از مرورگر ارسال می‌شود تلگرام در ایران بدون VPN/فیلترشکن در دسترس نیست.
- **اجرای خودکار** فقط تا وقتی صفحه باز است کار می‌کند. برای اجرای ۲۴ ساعته باید صفحه را روی یک دستگاه همیشه‌روشن باز بگذاری.
- **حافظه**: `localStorage` حدود ۵ مگابایت جا دارد؛ فقط ۴۰۰ روز قیمت و ۴۰۰۰ خبر آخر نگه داشته می‌شود. مدل خبری هر بار از همین داده آموزش می‌بیند (تا ۴۰ خبر ذخیره‌شده لازم است).
- **جدول‌خوان** خودرو/آهن با `DOMParser` فقط جدول‌های HTML ثابت را می‌خواند؛ صفحه‌هایی که با جاوااسکریپت پر می‌شوند ❌ می‌شوند (مثل نسخه‌ی پایتون).
- TSETMC و tgju API رسمی ندارند؛ اگر ساختار پاسخ عوض شد، فقط `js/tsetmc.js` یا `js/sources.js` را به‌روز کن.

## ساختار
```
web/
├─ dashboard.html    صفحه‌ی ورود: سرور ترموکس را پیدا می‌کند و به http://127.0.0.1:8787 می‌برد
├─ start-termux.sh   اجرای سرور
├─ server/           سرور محلی (Node، بدون وابستگی): app.mjs و server.mjs
├─ index.html        صفحه
├─ css/style.css
├─ js/
│  ├─ util.js        ارقام فارسی، تاریخ شمسی، اندیکاتورها
│  ├─ net.js         fetch مستقیم + timeout + قطع‌کننده مدار
│  ├─ store.js       localStorage
│  ├─ tsetmc.js      TSETMC، دیده‌بان کل بازار، اوراق، غربالگری
│  ├─ sources.js     tgju، بازار جهانی، اخبار، کدال، بورس کالا، جدول‌خوان
│  ├─ engine.js      سیگنال سهام/صندوق، بلک‌شولز، حباب سکه
│  ├─ finance.js     دلار ضمنی، نرخ مؤثر تسهیلات، صرف ریسک سهام، کاورد کال، حباب صندوق‌ها، نرخ بهره‌ی واقعی، پول کجا برود
│  ├─ nlp.js         تحلیل اخبار
│  ├─ config.js      تنظیمات پیش‌فرض
│  ├─ output.js      Claude، تلگرام، بله
│  ├─ cycle.js       یک چرخه‌ی کامل + ساخت جدول‌ها
│  ├─ dashboard.js   رندر تب‌ها و جدول‌ها
│  ├─ demo.js        داده‌ی ساختگی
│  └─ app.js         دکمه‌ها، تنظیمات، حالت خودکار
```

> این سامانه ابزار کمکی است، نه مشاور سرمایه‌گذاری. سیگنال‌ها قوانین ساده‌ی فنی و بنیادی‌اند و قبل از استفاده‌ی واقعی باید بک‌تست شوند.
